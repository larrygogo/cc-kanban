这一版解决一个老问题:一个需求牵扯好几个仓库,过去只能开好几个会话来回复述。现在一个会话就能同时访问多个目录,AI 在同一个上下文里协调所有仓的改动。另外,Claude 的选择题提问可以直接在对话窗里作答了。

## 一个会话,多个仓库

- **新建会话可附加目录**:面板里点「+ 附加目录」(或 Ctrl+点击最近目录)把其它仓加进来,一个需求只开一个会话——跨仓改动由 AI 自己协调,不用你在多个会话间人肉传话
- **已有会话中途也能加**:「查看改动」面板的仓库菜单里随时附加/移除目录;运行中的会话立即拿到访问权,断开的会话下次恢复自动带上
- **恢复不丢权限**:断线重连、接管重启都会自动回放附加目录——此前 `/add-dir` 是进程内状态,重启就丢
- **「查看改动」面板按仓切换**:文件树、文件搜索、diff 都能切到任一附加仓查看;非 git 仓自动只显示文件页签
- 贴纸卡片与侧栏条目上的 **+N** 小标示意跨仓会话,悬停可见全部目录
- 该能力由 agent 声明(目前 Claude Code 支持),不支持的 agent 不显示入口

## 提问选择题直接在对话窗作答

- Claude 的 AskUserQuestion 提问在对话窗弹出**可作答卡片**:多问题分页、多选勾选、自定义输入,答完直接提交
- 不想在这答?一键「去终端作答」;关掉对话窗时表单自动回落终端,不会丢
- 代答回执在时间线中正常显示,不再被误渲染成红色失败块

## 细节与修复

- 中途附加目录带审批防护:终端正挂着审批或提问弹窗时不注入命令,避免回车误触弹窗选项;含空格的路径正确处理
- 一批新错误提示补齐英文翻译;贴纸与侧栏的徽标对齐、菜单布局多处打磨
