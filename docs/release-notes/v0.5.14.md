这一版从根上处理了 Windows 终端「跑着跑着就僵住」的问题,顺手修好了安装器偶发的复制失败,并给终端补上了一批日常操作:右键复制粘贴、Ctrl+Enter 换行、API 报错提示。还有一个新快捷键:Ctrl+K 随时切会话。

## 终端僵死,从根上治

「会话跑着跑着画面定格、打字没反应」的元凶是 Windows 系统自带的终端宿主(conhost)内部死锁——它随系统更新,很多机器上跑的是几年前的老版本。Meowo 现在**自带一份新版终端宿主**(取自微软官方渠道并校验签名),所有会话自动换用,已知的死锁问题在源头上就不存在了。

万一还是遇到极端情况:输出停滞超过 30 秒会有明确提示(而不是让你对着静止画面猜它是卡了还是在思考);「结束会话」在任何卡死形态下都保证几秒内生效,连最顽固的内核僵尸也有专门的清理手段。

## 安装不再报「无法复制文件」

升级安装时偶发的「无法复制 app.exe」是旧进程还锁着文件——尤其是后台还开着第二个 Meowo、或进程恰好卡死的时候。安装器现在会先把所有相关进程清干净、**确认它们真的退出了**再开始复制。

## 终端更像个终端

- **右键复制/粘贴**:选中了右键就是复制,没选中右键就是粘贴(Windows 终端的惯例)
- **Ctrl+Enter / Shift+Enter 换行**:此前只有 Alt+Enter 能换行,现在三个都行,不会误触发送
- 修复了输入框偶发出现**两个光标**、以及画面多帧内容**交错重叠**的显示错乱
- 修复了在对话页恢复会话后发送的第一条消息**被静默吞掉**的问题——现在发送前会确认消息真的进了输入框,进不去就退回来明确告诉你

## API 报错看得见了

Claude 遇到 API 错误(过载、连接中断等)时,此前 Meowo 毫无动静,会话就静静挂着。现在三处都有提示:看板卡片标红、桌面通知(同类错误只提醒一次,不轰炸)、对话页里渲染成醒目的错误气泡。

## 更顺手的界面

- **Ctrl+K 快速切换器**:输入几个字直接跳到任何会话
- 看板状态点改回红绿灯直觉:颜色说明谁、闪烁说明急不急;检测到 Agent 停在待操作界面时显示「待操作」
- 侧栏搜索框、图片灯箱(滚轮缩放/拖拽)、提示气泡等一批细节打磨
- 双开 Meowo 时不再产生两个互相打架的实例(第二次启动会唤起已有窗口)
