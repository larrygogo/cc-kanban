这一版的主线是「把话说清楚，把事做对」：一轮六路并行的 UI/UX 全面扫描（69 条）加四轮交叉复核，逐条落地；另有三个实拍 bug——中途附加目录其实从来没生效过、切回终端页底部会缺一截、对话页看不到工具到底干了什么。

## 对话窗

- **工具调用像终端那样带详情**：Write 显示写了多少行 + 正文预览 + 剩余行数，Edit 显示前后对比，Bash 显示命令块；进行中的活动组默认展开，不用点开才知道在跑什么
- **审批卡不再抢走输入焦点**：你正在打插话时弹出审批卡，下一个空格或回车会落在「拒绝」上——现在焦点在输入框里就不抢
- **审批卡不再盖死内容**：它悬浮在对话底部约 500px 处，计划审批时刚写完的计划正文正好在这一段、滚到底也露不出来；现在卡片实高会让出可滚空白。「仅收起」也从单向门改成可再展开的折叠条
- **切去终端再切回来，阅读位置还在**（此前一律跳回底部）
- 「回到最新」浮钮与排队回执的「立即插话」不再被审批卡压住点不到
- 侧栏折叠分组不再吞掉你正开着的会话（日期分桶的键是固定的，折过一次第二天的新会话会连同当前会话一起被藏起来）
- 工具名不再中英混排（Grep/WebFetch/Task 等都有了中文名）；并行工具跑起来时读屏不再被逐行打断
- markdown 图片有了兜底：远端大图限宽自适应，本地路径降级成文件名标签而不是一个碎图标
- 另一个 Meowo 会话发来的消息不再摊成一屏 XML，渲染成带来源的消息块，长消息可折叠

## 附加目录（`--add-dir`）

- **中途附加目录其实从来没生效过**：我们自己发给 CLI 的命令带了引号，而 claude 的 `/add-dir` 不做引号剥离——引号进了路径字面量，还让它不再以盘符开头、被当成相对路径拼到当前目录后面。库里记上了、运行中的进程却没拿到访问权，界面在说谎
- 手打 `/add-dir "C:\…"` 同样修好了，并且会顺带落库（此前手打的不进库，恢复会话后丢）
- 资源管理器「复制为路径」带来的引号，现在在新建面板、远程、中途附加三条入口都能识别

## 终端

- **切回终端页不再看到残帧**：底部输入框的边框与状态行缺一截、只剩半个字符，拖一下窗口才好——原因是隐藏期间画布失效，而既有的自愈全都指望「尺寸变化触发重绘」，尺寸没变时那条路是断的
- **鼠标上报时选不了字**有提示了：按住 Shift（macOS ⌥）拖动可选择；macOS 上补齐了 ⌥ 拖选的开关
- 含中文的行上，文件路径链接的位置不再左偏、Ctrl+点击点不开
- 终端字号首帧直接用上次生效值，不再先按 12 号画一屏再重排
- 新建会话面板：打开即聚焦目录框（回车直接启动）、未装 CLI 时给「去安装」入口、预填的 Agent 没装被换掉时会说明
- 右键菜单按 Esc 关闭后，焦点回到终端（此前继续打字没反应）

## 看板与贴纸

- 切 tab 时不再闪一下「还没有会话」再换成真列表
- 刷新失败时给细横幅说明「显示的是缓存」，用量读数陈旧会降饱和并标注上次更新时刻
- 「全部」tab 里在线与历史会话之间有了分界线
- 主目录启动的会话，「仓库」栏不再显示成你的用户名
- 搜索框已经开着时再按 Ctrl+F 会把焦点抢回来；设置窗也有了 Ctrl+F 与清除按钮
- 连续归档时撤销提示不再无限堆叠

## 设置与更新

- 更新的三个阶段（有新版 / 正在下载 / 已就绪）分开表述，不再都说「有新版本」；「重启并更新」按下后有进行态
- Windows 上登录提示不再念错终端名（选过的终端被卸载后也不会再念旧名）
- 弹层里拖选文字时手滑到遮罩上松手，不再把弹层连同草稿一起关掉
- 远程端口填错有行内说明，不再静默弹回默认值
- 账号分区搜索别家 agent 名（如「codex」）不再零结果零入口

## 手机远程

- **恢复双指缩放**（此前被禁掉，是无障碍硬伤），输入控件钉 16px 防止 iOS 聚焦时整页放大
- 刘海屏顶栏不再把菜单按钮挤到标题行上
- iOS 软键盘弹出时不再把页面顶走、输入框藏到键盘后面
- 配对失败能区分「令牌不对」与「连不上桌面端」；配对页跟随主题
- 加载 1.2MB 的对话窗时有加载提示，不再是几秒白屏
- 桌面端离线的判定从最长 60 秒压到几秒
- 远程页的错误提示纳入统一的中英文映射

## 视觉与无障碍

- 小字对比度按**叠层后的实际卡面**重新校准（此前按裸底算，落到卡片和悬停态上不达标）
- 同一张「待批准」卡上的三种橙色统一；浅色主题下子任务胶囊、已完成待办的对比度补齐
- 桌面端多处点击热区补到 24px，手机端关键按钮补到 44px
- 开启「减少动态效果」后，转圈指示不再定格成一个豁了口的环
- 文案规范收口：动词统一（中断/收起/跳过权限确认）、状态词统一（等待输入/已断开）、去掉分号与破折号、拆长句、去黑话
