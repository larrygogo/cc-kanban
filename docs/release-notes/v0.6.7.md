这一版修两个实拍卡点：把会话切到 kimi 之后「什么都没了」，以及手机上结束不了会话。顺带把 0.6.6 之后攒下的排版、性能与发布链改动一起带上。

## kimi：不再卡在「是否信任此目录」

- **切换到 kimi 后会话消失**：kimi 0.40 起每个目录首次打开都要在终端里确认信任，对话页看不到也答不了这道提示；信任屏期间它不发任何 hook，新会话进不了看板，而旧会话已经收尾——看板上就像切换失败。现在起进程前会替你把这个目录写进 kimi 自己的信任名册，直达主界面
- 新建会话、恢复会话、接管重启走同一条预信任，多账号按实际生效的账号写
- 升级 kimi 后旧信任像被清空一样重新弹提示，是它换了键算法，不是回归；本版按新算法写入，并附真机探针钉住一致性
- 只写 kimi 自己会写的两个字段，只对你亲手发起的启动生效。注意它的信任语义是**启用该目录的项目级 MCP 服务器**

## 手机远程

- **可以结束会话了**：此前远程刻意不放行结束命令，但接管与写终端早已能做到同样的事，拒绝它只是少一个入口。现在对话页标题栏与侧栏菜单都能结束，只作用于本会话进程
- 首屏更快：静态资源预压缩并长缓存，终端视图与改动面板拆成按需加载

## 对话窗

- 长回复恢复文档排版层级：标题拉开、段距对齐、行内 code 底色减淡
- 正文放大到 15px、深色主题降对比防晕字、字距归零
- 鼠标停在工具输出块上时对话区不再「卡住」：内层滚到边界后会带动外层

## 看板与贴纸

- 更新提示分两档：有新版只亮红点，下载完成才出一键安装横条；红点回到齿轮角标，不再挤溢底栏
- 看板四个 tab 的列表查询改走索引

## 发布与底盘

- macOS 拆 arm64 与 x64 两个独立 dmg，发版流程并行化提速
- 原子写残留的临时文件会被回收
- 数据库 schema v16：丢掉从未写入过的 events 表，开库自动迁移
- E2E 接入 CI 定期通道
