这一版把「后台还在干活」这件事补完整了：fork 出去跑的子任务、在后台跑的命令，现在都能在进度面板里看见，会话状态也不会再在它们跑着的时候说「等你输入」。另外修了一批性能与安全问题，其中「退出 agent 后终端一动鼠标就刷字符」是这版最容易撞上的那个。

## 子任务与后台任务

- `/code-review` 这类 fork 出去跑的 skill，进度面板终于能看到它派出的子任务（此前是整片空白，该形态从来没被支持过）
- 展开子任务不再张冠李戴：同一条命令跑过多次时，配对不会再错位
- fork 出去的 skill 跑完不再永远挂着「运行中」（实拍：一场 11:36 就结束的审查挂了三个半小时）
- **后台命令也算在跑的活儿**：主回合停了但后台命令还在跑时，会话不再显示「等你输入」，进度面板也会列出它

## 终端

- **退出 agent 后终端不再「一动鼠标就刷字符」**：agent 崩溃或被强制结束时来不及收回的鼠标上报、括号粘贴、备用屏、隐藏光标，现在由 Meowo 一并收回，外部终端的两条路（同步打开、直接开在你的终端里）都覆盖
- Shift+滚轮在 claude 全屏界面下真的能滚了：此前它恰好在最需要的场景里什么都不做
- 点完切换模型立刻关窗，不会再打断 agent 正在跑的那个回合

## 性能

- 长会话流式输出不再吃掉小半帧：任务列表重建加了缓存，实测快 6~8 倍
- 活跃会话不再每 2 秒重传整份终端回放（最多 1 MiB）
- 侧栏几百条会话时不再每次刷新都整表重建
- 停在已结束会话上的空转探测会退避并停下（此前每小时数千次空转）
- 托盘右键菜单开窗口不再白屏卡顿
- 文件面板的缓存加了上限，不再只增不减

## 安全与更新

- 「重启并更新」不再把托管会话变成孤儿进程（Windows）
- Windows 上 API 中转的密钥不再出现在命令行上（同机任意进程都能读走）
- 手机端打开链接同样只放行 http/https，与桌面端一致
- 日志与设置出口的代理凭据做了脱敏，host/port 保留以便定位

## 用量

- Opus 泳道不再在过渡期被整条吞掉
- 贴纸的模型周限取用得最满的那条，不再可能把 83% 的那条藏起来

## macOS

- 贴纸窗恢复可拖拽边框
- 建窗失败后 Dock 图标不再永久常驻
- 长路径下的进程判活与终端聚焦不再失灵（`ps` 输出被按 79 列截断所致）
