这一版把「找回过去」做顺了:侧栏能全文搜索对话内容,终端有了 Ctrl+F 内搜索;后台子任务的状态终于靠谱,更新也学会了趁你退出时静默装好。另有一大批状态准确性、安全与性能修复。

## 搜索:聊过的都能找回来

- 侧栏新增「搜索对话内容」:全文检索最近 200 个会话(含已归档)的对话记录,每个会话给一条命中摘录,点击直达
- 会话搜索范围扩大:除了标题和目录,便签内容与最近往来(你上次说的、AI 上次答的)也参与匹配
- 切换 tab 不再丢搜索词;搜索时不折叠未运行的会话

## 终端与输入更顺手

- 终端支持 **Ctrl+F 搜索**,并换用 WebGL 渲染(不支持时自动回退);emoji 不再被裁半
- 文件**拖进对话框即成附件**;输入 `@` 补全文件路径(即时目录浏览 + 全局模糊匹配)
- 按 `↑` 取回上一条发过的消息;草稿按会话各自保存,切走再回来还在
- 对话里的代码块有语法高亮了;消息带日期分隔条,悬停可看精确时间

## 后台子任务:状态终于准了

- AI 委派的后台子任务完成后,状态会正确翻转(此前主 AI 主动查收结果时,界面会永远显示「进行中」)
- 主回合结束但后台子任务还在跑的会话,不再被误标成「等待中」——贴纸和看板都按「后台忙碌」显示
- 子任务块显示执行时长,跑着的时候实时走秒

## 更新:退出即装,不再弹窗

- 更新下载好后点「稍后」,退出 Meowo 时会**自动静默安装**,下次启动就是新版
- 升级安装不再弹出进度窗口(0.5.15 实测会弹且界面错乱,已改全静默)

## 会话状态与通知一批修复

- 「等待你回复」通知不再同一回合重复弹;回合刚结束时的迟到事件不再把会话顶回「运行中」
- 在外部终端跑的会话,提问和审批留在终端里作答,GUI 不再抢走权限框
- AI 用 `/clear` 原地开新会话时,看板自动折叠成一张卡,开着的对话窗自动跟随新段
- Claude Code 新版标题动画(月相帧)正确识别为运行中,长任务不再被错挂黄环
- GUI 托管的会话不再被空闲回收误结束;整理会话历史(compact)后工作区目录不再漂移

## 安全加固

- 中转接口的模型列表请求增加同源校验;粘贴附件的可执行扩展名一律中和;确认弹窗绑定来源窗口;内容安全策略收紧图片外链;git diff 路径穿越守卫补齐反斜杠

## 性能与细节

- 长会话流式输出的渲染改为增量更新,不再越聊越卡;贴纸窗会话判活开销降到毫秒级
- GBK 编码的文件(中文 Windows 常见)不再满屏乱码
- 批量归档多选(Ctrl+点击);连续归档时撤销互不覆盖;审批卡 Esc 拒绝改两段确认
- 代理地址删空后正确恢复直连;切换图片预览不再残留上一张;设置页滑块调完即存
