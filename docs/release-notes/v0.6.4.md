这一版是一轮系统的交互体验整治：用一份 146 条的交互清单（`docs/ux-backlog.md`）逐条核对清零，覆盖看板、对话窗、托管终端、设置、窗口管理与通知六个面。最有感的几个：kimi 会话不再被误报成「待交互」、审批卡能分级警示危险命令、等待审批的 toast 长驻且一键直达、子任务面板逐条显示（对齐 TUI 的 001/002）、设置终于能搜索了。

## 状态判定与提醒

- **kimi 会话不再把「正在干活」误报成「待交互」**：屏幕规则适配了当前版 kimi TUI 的工作指示（`⠴ Agent Running`、月相提示行）——此前持有 PTY 的实例会把整块活跃工作屏判成空闲
- 等待/审批不再因事件时间戳跳动反复弹通知；审批类 toast 改为长驻 +「打开会话」按钮
- 「运行中→空闲/阻塞」的看板落地从最坏 1.7s 压到约 1s（高优通道绕过合并节流）
- 外部会话的状态角标弱化显示（那是按记录推断的，不是实时判定）；屏幕识别拿不准时降级为中性点而不是自信的「等你」
- macOS 通知换用 UNUserNotificationCenter，不再串行阻塞投递

## 对话窗

- 对话内容实时性翻倍：transcript 文件变化直推事件，不再只靠轮询（兜底轮询降到 2s）
- 进度面板的子任务**逐条**显示（一次派多个子任务不再合并成「×N」一行），各自的状态与耗时实时更新
- AskUserQuestion 多问题表单可以卡内作答了（自动识别当前聚焦第几题，认不出就一字不写）
- 审批卡：危险命令（`rm -rf`、`sudo` 等）的允许按钮红色警示；长命令支持展开全部/复制；提交失败不再静默
- 「加载更早」改成分页向上翻，不再一次性全量重读
- 斜杠补全支持子串匹配 + 参数提示；`@` 文件补全；代码块有语法高亮（按需加载，不影响启动）
- 切会话改骨架屏；轮询连续失败单列「同步中断」，与「agent 退出」区分开
- 命令输出里的终端转义码不再渲染成乱码（如 /compact）

## 托管终端

- 终端里文件路径 Ctrl+点击直达文件管理器；链接悬停有提示；右键菜单（复制/粘贴/全选/搜索）
- 对话窗与外部终端同连一个 PTY 时：失焦一方不再乱发 resize（TUI 不再反复重排），另一方在线时提示「两边同时输入会交错」
- 恢复/接管用当前终端网格起 PTY，首屏不再重排；临时会话转正不再整只重挂终端
- 启动失败带终端尾部原因；等待终端就绪显示秒数；假死横幅加「结束并恢复」；强制结束的会话明确标注「进程可能仍在后台残留」
- 回滚行数（scrollback）进设置，500–50000 可调

## 看板与新建会话

- 新建会话有「正在启动」占位卡，不再面板一闪而灭毫无反馈
- 高风险启动档（bypassPermissions/yolo）下拉里红色警示 + 风险说明
- 中转（relay）启用时模型档置灰注明「由中转固定为 X」
- 便签超 3 行折叠、编辑中滚动不再丢草稿、星标卡片移动有动画、切 tab/搜索切换期列表灰化防抖
- 搜索也能命中便签内容；侧栏会话列表支持搜索（Ctrl+F）

## 设置与引导

- **设置可以搜索了**（行/卡片/分组/分区四级过滤）；设置窗可纵向拉高；外观分区有迷你贴纸实时预览
- 引导新增「连接你的 AI CLI」与「Meowo 如何读到进度」两步：明说会往 CLI 配置写 hooks、写前自动备份、怎么移除
- 登录等待显示「已在哪个终端打开、最长 5 分钟」；安装可取消；安装失败日志一键打开
- 账号错误英文界面不再蹦中文；确认框按钮说清后果（「删除账号」「结束并重开」），可逆操作不再用危险红
- 更新下载可取消

## 窗口与托盘（Windows）

- 窗口位置/尺寸/吸附边/置顶统一进 settings.json（localStorage 旧值自动迁移）；折叠态禁止缩放，根治「尺寸毒化」
- 托盘：单击开合贴纸、**双击打开对话窗**（恢复老习惯）；菜单项与 macOS 对齐；首显不再抢焦点
- 吸边：双屏只吸虚拟桌面外侧边（内侧边不再误触）；拖到边缘显示落点幽灵轮廓；展开过渡不再布局抖动
- 新增点击穿透模式：设置里开启后贴纸不吃鼠标，按住 Alt 临时恢复交互

## 无障碍与键盘

- 看板卡片收拢为单个 Tab 停靠点 + 卡内方向键；侧栏 roving tabindex；tablist 全键盘可操作
- 弹层统一焦点陷阱 + 背景 inert；审批卡改 alertdialog 并自动移焦
- 状态点不再每个都是 live region（读屏播报风暴），全窗只留一个汇总播报
