这一版给对话窗口装上了「文件 / 更改」面板——看代码、看改动都不用离开对话;新增「切换引擎」:一段对话可以换个 AI 接着跑;Windows 换上全新的一键安装器。粘贴图片、审批提醒、任务进度也集体变懂事了。

## 文件与更改:代码就开在对话旁边

对话窗口标题栏多了个入口,点开是右侧停靠面板(对话不会被盖住):

- **更改**:当前目录在 git 仓库里时,列出工作区的全部改动文件,点开就是着色的 diff——新增绿底、删除红底、代码带语法高亮
- **文件**:整个项目目录的文件浏览器,点任何文件直接预览(带行号和语法高亮)
- 面板宽度随手拖,还能一键最大化(对话区临时让位),折叠后再展开原样还在

## 一段对话,换个 AI 接着跑

模型下拉里新增「切换引擎」:把当前会话的完整上下文交接给另一个 AI(Claude Code / Kimi / Codex 等任一已安装的),在同一目录继续这段任务。旧会话保留可回看,新会话的时间线里能直接看到切换前的全部对话;侧栏里带「引擎切换历史」徽标,链上各段随时跳回。

## 全新一键安装(Windows)

新安装器界面清爽直观,一路下一步即可;「自定义安装」里还能直接勾选轻量模式。没有 WebView2 的环境会自动回退到经典安装界面。升级安装也根治了「无法复制文件」:改用 Chrome/Firefox 更新器同款做法——先把被占用的旧文件挪开再写入,旧进程杀不死也能装成功。官网下载页已指向新安装包。

## 粘贴图片,一次多张

对话页粘贴图片发送整个重做:多张图片可以一次发,逐张交给 AI 自己读取。发送前自动快照你的剪贴板、发完原样还原——不会顶掉你刚复制的内容;任一环节失败会静默回退为文件路径方式,绝不会把错的内容发给 AI。

## 审批不再抢窗口

- 正在 A 会话阅读或打字时,B 会话的审批/提问**不再把窗口瞬间切走**:改为侧栏亮徽标 + 任务栏闪烁,点过去审批卡仍然可答(整个等待期有效,不再 10 秒超时悄悄退回)
- Claude 计划模式的「plan 已写好,是否执行」批准提示现在能被识别:看板显示待操作、对话页弹出审批卡(此前它悄无声息,会话看起来像在空转)
- 有待审批/提问时,终端不再误报「输出停滞疑似卡死」——静止本就是在等人

## 任务进度看得见了

- 标题栏新增「进度」按钮:浮出任务清单 + 子任务面板,进行中的排最前、完成的沉底
- 支持 Claude 新版任务列表:此前这类任务完全不显示,现在看板、贴纸、进度面板都有
- 后台子任务完成后,对话页的状态会正确翻转为完成/失败(此前一直停在「进行中」)
- Kimi 会话里粘贴发送的图片,回看历史时也能显示缩略图了

## 轻量模式:只要贴纸

设置与首次引导新增「对话窗口功能」开关:关闭后只保留桌面贴纸,会话统一在外部终端打开,审批和提问也回到终端里作答——想要极简陪伴形态的可以一试。

## 细节打磨

- 上下文占用环在 100% 时数字不再溢出贴边
- 会话菜单的「星标置顶」简化为「置顶」
- 待办与子任务的状态图标统一为徽章样式
