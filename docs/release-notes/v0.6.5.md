这一版的主线是「听你说话」：大量来自实拍的修复——手机端远程会话链路打通、图片附件在各家 CLI 下都正常了、一长串「看着别扭」的细节（消息偶尔双显、标题被系统文本污染、审批卡把输入框往下推）都有了终态。另有四个结构性专项：审批卡零位移 overlay、界面缩放下发对话窗、原生吸附预览窗、Ctrl+K 命令面板。

## 手机远程访问

- **新建会话不再报「参数无效」**：远程桥缺 `extraDirs` 字段，手机端每次新建都被拒（400）；顺手给全部 40 条远程命令加了参数契约防护测试，同类漂移以后直接变红
- 新建成功后自动进入新会话（此前落回「去侧栏选会话」的空态），启动中有占位画面，认领后无缝切到真会话
- 会话列表抽屉不再每次打开都闪「加载中」（首开后保持挂载）
- 待审批的通知在手机上点开一条不再把其他会话的审批通知连坐清掉

## 图片附件

- **kimi 发图修好了**：kimi 在 Windows 上的贴图键是 Alt+V（不是 Ctrl+V），此前发图静默降级成指令文本打进终端——现在和原生终端一样出现 `[image #N]` 占位符
- 即使走了文本回退，图片路径也会被解析成预览图，注入的指令原文不再整段上屏
- 运行中发纯图片消息，「（附件）」排队回执不再永久残留
- 会话标题不再被机器文本污染：kimi 的 `<system>图片压缩说明</system>` 注记、Meowo 自己的附件注入指令，都不会再变成会话标题

## 对话窗

- **审批/题面卡改悬浮 overlay**：出现时不再把输入框和消息往下推（彻底零位移）
- **Ctrl+K 命令面板**：搜会话 + 执行命令（新建/切视图/收侧栏/回最新/速查表）
- 界面缩放（设置里的字号密度）现在同时作用于对话窗
- 消息不再偶尔双显（kimi 日志双写两行常差 1ms，去重从同戳全等放宽为 2s 容差）
- 运行指示从脉冲圆点改成盲文「贪吃蛇」（三点顺时针爬行，kimi TUI 同款）
- 「回到最新」带未读计数；跨段接续与分隔行不再虚增计数

## 看板与状态判定

- 活动态判定三处同源（看板/侧栏/后端 tab 归属同一阶梯）：已结束的会话不再被残留画面误报「待交互」
- 待办列表有「上一任务」语义：新任务开始时旧清单自动折叠收编，看板进度只算当前任务；顺手修了四条待办失真路径（空参数误清整表、缺标题行静默丢失、claude 任务创建丢失、多卡归属错乱）
- 外部会话的状态角标恢复全亮度（「按记录推断」的区分保留在悬停提示里）
- 点一条通知不再连坐清空其他待审批通知

## 窗口与吸附（Windows）

- **原生吸附预览条**：拖到屏幕边缘时，落点位置直接画在屏边（不再是窗口内的小提示）；首次拖拽即有预览（启动预热）、压在贴纸之上、厚度与真实缩略条一致、贴边侧无圆角
- 托盘单击对折叠成细条的贴纸有效了（展开带到眼前，不再「点了没反应」）
- 重启后通知中心的旧通知启动时清场（那些点了没反应的死链接）

## 设置与 agent 管理

- **agent 版本可见 + 一键更新**：设置 → Agent 分区显示各家当前版本，有新版时一键更新（claude/codex/gemini/opencode 走 npm，kimi 走官方渠道）
- 设置搜索现在能命中下拉选项内容（如搜 "WezTerm"）
- 远程访问的二维码按**实际监听**端口生成——多实例并存时不再指向另一实例的服务
- Relay 模型输入框按 Esc 不再误关整个设置窗；设置保存错误英文界面不再蹦中文

## 终端

- 「结束并恢复」在 ConPTY 僵死场景能一步走完（等进程真退出再启动，注册缝隙归零）
- 外部视图离线后终端网格立刻夺回（不再只显示上半截）
- kimi 空闲输入框不再被误判成 fallback 灰点
- 贴纸悬停展开时窗口不再凭空消失

---

**测试底盘**：前端 800+ 用例、后端 390+ 用例全绿；远程桥 40 条命令有参数契约防护；两个真机探针（kimi 贴图、终端回车）留在 `app/src-tauri/tests/` 可复跑。
