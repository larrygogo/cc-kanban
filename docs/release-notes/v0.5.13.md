这一版专修一类最恼人的问题:会话看起来还在跑,实际已经没了响应——以及点了「结束会话」却结束不掉。

## 结束会话,保证生效

Windows 上卡死在系统管道里的 Agent 进程,普通的结束手段会静默失效,界面就一直显示「运行中」。现在结束会话带三段升级:一秒内没退就连它拉起的子进程一起清掉,三秒内仍没退就强制收尾——无论进程卡成什么样,界面都会在几秒内解锁。应用退出时也会把 MCP 等孙进程一并清理,不再往系统里漏进程。

## 界面卡顿不再拖死 Agent

此前对话窗如果一时消化不过来终端输出,压力会一路反压到 Agent 的输出管道上,把它活活憋死(表现为终端定格、打字无回显)。现在输出链去掉了反压:界面忙不过来时丢弃的只是实时画面帧,事后自动按缺口补齐,Agent 全程不受影响。

## 恢复会话后,终端能打字了

在对话页恢复一个历史会话后,切到终端页打字没有回显——后台旁路挡住了新终端的输入通道。已修复,恢复流程不再被旁路短路。
